# DTDM04 Model Output Parameters 對照

## 摘要

2026-10-22：依使用者提供的欄位，確認此群組為「模型輸出」，不是 Module Output（模組輸出）。已知四通道各有一組模型相關設定與唯讀結果；尚未取得運算式、量綱與訊號路徑，**不能據此實作或宣稱相容**。

在目前 DTDM04 v1.5 手冊的擷取文字搜尋「模型」「Model Output」「1990」，未找到直接對應；這不證明設備沒有此功能，也可能是文件版本或文字擷取限制。以使用者提供表格作為欄位依據，不假造章節。

## 已知欄位

以下位址依原表視為十六進位；Table Index 為另一個索引欄，不是 Modbus 位址。原始資料型別照錄，不在未確認前修正。

| 欄位 | Table Index | CH1～CH4 位址 | 範圍／預設 | 已知與待確認 |
|---|---:|---|---|---|
| Model Output Switch | 2448 | 0x1990～1993 | 0～1／0 | 開關；0／1 的詳細動作、停用時狀態與結果待確認。 |
| Model Output Percent | 2452 | 0x1994～1997 | 0～150／0 | 百分比設定；是否 1% 刻度、模型輸入或實體輸出要求未知。 |
| Model Output Gain | 2456 | 0x1998～199B | 0～9999／0 | 增益；倍率刻度與量綱未知。 |
| Model Output Time Constant | 2460 | 0x199C～199F | 0～9999／0 | 時間常數；秒／0.1 秒等單位及零值行為未知。 |
| Model Output Base Temperature | 2464 | 0x19A0～19A3 | −30000～30000／0 | 原表標 U16，與負值範圍矛盾；需確認是否 S16／有號編碼及溫度刻度。 |
| Model Output Value | 2468 | 0x19A4～19A7 | 未提供，唯讀 | 原表 U16；實際是模擬 PV、預測溫度、補償值或 MV，不能僅依名稱判定。 |

## 推論與禁止直接採用的假設

增益、時間常數與基礎溫度的組合，可能描述製程動態／模擬溫度模型，但也可能有其他用途。不能僅憑欄位認定為一階模型、Smith Predictor、前饋補償、Sensor 備援或實體功率輸出。

即使已有 FbLeadLag，也尚未確認其傳遞函數、初始條件與輸入輸出符合此模型。此項列為「規格待確認」，不列為已有完整實作，也不在 FB 完成數量中新增一個已建置項目。

## 需要補齊的規格

- [ ] 運算式或功能說明：模型輸入是設定百分比、實際 PID MV，還是其他來源？
- [ ] Model Output Value 的量綱、正負號、刻度及用途。
- [ ] Percent、Gain、Time Constant、Base Temperature 各自單位與有效範圍。
- [ ] 開啟後是否替代控制 PV、只顯示診斷，或產生其他候選訊號。
- [ ] 初始化值、停用／重新啟用、參數變更與零時間常數的行為。
- [ ] 對應工具畫面說明、較新手冊／版本註記，或已知輸入輸出範例。

## 放入本架構的原則

若確認為純運算模型，可設計單一實例 L04 FB；L05 選來源、提供 dt 並決定誰使用結果。若涉及模擬 PV，正式量測與模擬資料必須可區分，不能無聲覆蓋 Sensor Snapshot 或 Safety 的量測來源。若結果為候選 MV，仍經現有 SYSTEM／Safety／輸出流程，不直接寫硬體。

本次僅記錄已知欄位與疑點，沒有新增模型程式、Register 或改變任何輸出。
