# DTDM04 Input Switch Over Parameters 對照

## 摘要

2026-10-22：依使用者 Register 表及重新讀取的 DTDM04 v1.5 第 3.3.4 節（頁 3-8～3-9），確認此功能為雙 Sensor 量測範圍切換，且中間區域會取兩來源的算術平均。**不是單純二選一 Selector，也不能把上下門檻直接當作一般遲滯帶。**

目前尚無專用 Switch Over FB，未實作／未測試；本次只補文件並修正先前缺項描述。建議一個 L04 實例接收兩個有品質資訊的 PV，L05 決定來源；兩組 SwIn 是產品容量，不固定在 L04。SYSTEM／Safety 保留既有異常及輸出權責。

## 已確認的量測選擇

手冊範例使用低切換值 200°C、高切換值 400°C：

1. Source1（低溫）低於 200°C，使用 Source1。
2. Source1 高於 200°C，再判斷 Source2（高溫）；Source2 高於 400°C，使用 Source2。
3. 第二步中 Source2 未高於 400°C，使用兩個來源的平均值。

手冊另以文字描述兩輸入介於切換值之間時，參考兩者平均。範例的判斷順序不等同只根據單一 PV 選擇區域；不要擅自改成「平均值超過上限就用 Source2」。

上述文字對 Source1 恰好等於低門檻等邊界未完整說明，兩個來源落在不同區域／嚴重不一致的情況也須另定正式契約。可建議採 Source1≤L 優先低來源，否則 Source2>H 採高來源，其餘平均，但在確認前不可稱為已驗證的設備定義。

## 欄位對照

以下為 SwIn1／SwIn2 的 DTDM04 十六進位位址；本專案另行規劃，不直接沿用。Table Index 不等於位址。

| 欄位 | 位址 | 定義／責任 |
|---|---|---|
| Source1 | 0x1700／1701 | 0～3=In1～4，低溫來源；L05 路由。 |
| Source2 | 0x1702／1703 | 0～3=In1～4，高溫來源；L05 路由。 |
| Sensor Low Limit | 0x1704／1705 | 原表 −32000～High，預設 −32000；整體量測界限的精確作用需明訂。 |
| Sensor High Limit | 0x1706／1707 | 原表 Low～32000，預設 32000。 |
| Switch High Value | 0x1708／1709 | Switch Low～Sensor High，預設 1000。 |
| Switch Low Value | 0x170A／170B | Sensor Low～Switch High，預設 0。 |
| Action when Sensor Fail | 0x170C／170D | 0=切換另一來源、1=維持目前來源。使用者表預設 0，手冊表預設 1，有版本／資料差異需記錄。 |
| Selected Source | 0x170E／170F | 0=Source1、1=Source2、2=both；both 表示平均運算，不是隨便挑一個。 |
| Error Status | 0x1710／1711 | 0=皆正常、1=Source1 NG、2=Source2 NG、3=皆 NG；可分別記錄兩來源品質。 |
| Switch PV | 0x1712／1713 | 唯讀 S16 最終 PV；特殊編碼見下節。 |
| Reserved | 0x1714 起 | 不推定新參數。 |

一般溫度刻度為 0.1°C／°F，類比量無單位。建議本專案溫度 PV／門檻採 int32_t 的 0.001°C；其他量綱需明確定義，兩來源不可任意混用。

## 錯誤碼與品質不能混入數值

原 Switch PV 將 0x8001 初始化、0x8002 未連接、0x8005 超規格、0x8006 輸入禁能放入同一個 Register。這些是狀態編碼，不是正常負溫，不可乘以 100 後進入內插、平均或 PID。

本專案建議 L04 各來源使用 value、valid、quality 分離；輸出同樣提供 value／valid、selected_source、兩來源錯誤旗標與降級狀態。若需相容 DTDM04，僅在協定轉換層編碼上述 sentinel。

「remain the same」指維持目前來源，**不代表無條件保留前次 PV 並宣稱有效**。若選中的來源失效，應提供明確無效結果，讓既有 SYSTEM 依原架構處理；若要保留診斷用舊值，必須標示 invalid／stale，不供控制直接使用。

## 故障與恢復的待定契約

| 情境 | 處理方向／仍須確認 |
|---|---|
| 單來源失效，允許切換 | 另一來源有效且適用範圍時才替代；記錄 degraded，不能把錯誤來源也納入平均。 |
| 單來源失效，維持來源 | 維持來源選擇與輸出有效性分開；不可隱藏來源錯誤。 |
| both 平均期間一側失效 | 「維持目前來源」對 both 的作用尚未明訂，不能直接假定仍可平均。 |
| 兩來源都失效 | 不產生有效 Switch PV；沿用既有 Sensor 異常處置。 |
| 故障來源恢復 | 是否立即回正常區域、需連續有效幾次或重新初始化，需明訂；不直接沿用上次選擇。 |
| 同一來源指定兩次 | 原表允許相同預設來源，不能宣稱設備禁止；本專案須決定接受為無冗餘配置，或在啟用時拒絕。 |
| 來源單位／時間不同 | L05 檢查量綱、有效性、年齡與取樣時間差；不能把不同時刻的值任意平均。 |
| 設定變更／停用／重啟 | 定義初始選擇、是否清除歷史及診斷狀態。 |

Sensor Low≤Switch Low≤Switch High≤Sensor High 可作整組 Apply 驗證。Switch Low==High 原表未禁止，但平均區及等號政策需明訂；界限外是夾制、無效或僅範圍描述也需釐清。

平均運算建議先以 int64_t 加總，避免 int32_t 溢位；奇數和包含負值時的 0.001°C 捨入須一致定義。這是實作規劃，尚未新增程式。

## 串接方向與待辦

L03 提供兩來源 Snapshot 與品質；L05 選擇並檢查資料；L04 Switch Over 產生 Switch PV；L05 再將其作為選定控制迴路的 PV。Sensor 原始結果保留，不以 Switch PV 覆寫硬體 Snapshot。SYSTEM 是否繼續運作仍由既有權責處理。
