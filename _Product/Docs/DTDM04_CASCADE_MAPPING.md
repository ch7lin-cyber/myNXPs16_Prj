# DTDM04 Cascade Control Loop Parameters 對照

## 摘要

2026-10-22：依使用者提供的兩組 Cascade Register 欄位，對照先前已讀取的 DTDM04 v1.5 第 5.1.7 節（頁 5-9～5-10）。可確認需要 SV 轉換、上下限、Offset、濾波、主／副控 AT、一鍵校準及副控保護溫度。

**FbCascadeCoordinator 目前仍為空架構，尚未實作。** FbPid 可重用，但兩個 PID 不代表完整串級功能。此次只補文件，不新增 Register、演算法或輸出動作。

以本專案架構為主：L04 計算數值與狀態，L05 選來源並串接；SYSTEM／Safety／輸出服務維持最終輸出權責，不照搬設備直接操作輸出的流程。

## 欄位與責任

原始位址為十六進位，Table Index 為另一個索引，不是 Modbus 位址；本專案不直接沿用這些位址。Loop Mode 與 Control Loop Parameters 是同一份設定，不重複建兩份。

| 欄位 | SET1／SET2 位址 | 已知定義 | 對應位置／缺項 |
|---|---|---|---|
| Loop Mode | 0x1404／1405 | 0=Single、1=Cascade | L05 控制鏈選擇；與 Control Loop 共用。 |
| Slave SV Mode | 0x14B0／14B1 | 0=absolute、1=deviation，預設 1 | L04 協調器的換算／界限模式。完整 MV→SV 公式仍待定義。 |
| Slave SV Limit High | 0x14B2／14B3 | S16，上限 32000，預設 600 | 絕對模式為實際 SV 上界；相對模式為相對主控 SV 的上偏差。 |
| Slave SV Limit Low | 0x14B4／14B5 | S16，下限 −32000，預設 −100 | 絕對模式為實際 SV 下界；相對模式為相對主控 SV 的下偏差。須 L≤H。 |
| Slave SV Offset | 0x14B6／14B7 | S16，−32000～32000，預設 0 | L04 補償數值；加補償、濾波與限幅順序尚未由欄位明訂。 |
| Slave SV Filter Num | 0x14B8／14B9 | 0～60，預設 2 | 只知道濾波強度設定；不能直接認定為秒數、移動平均筆數或一階時間常數。 |
| Cascade AT Mode | 0x14BA／14BB | 2=Slave AT、3=Master AT | L05 協調兩個 FbPid 的 AT；不能將單一 FbPid 的 AUTO_TUNE 視為整個流程完成。 |
| One Key Calibration | 0x14BC／14BD | 表格：讀為 9 時，寫任意值更新副控 SV 上下限 | L05 命令／狀態與校準流程；本次尚無演算法或穩定判準。讀狀態與寫命令應分開建模。 |
| Max Slave Temperature | 0x14BE／14BF | 加熱時副控 PV 大於門檻，副控輸出歸零；0=不生效，單位 0.1 度 | 保護條件由明確比較產生，交既有 SYSTEM／Safety／輸出路徑執行，L04 協調器不得直接寫硬體。 |
| Reserved | 0x14C0 起 | 保留 | 不新增推測功能。 |

溫度欄位的原表單位多為 0.1°C／°F，類比量則無單位；本專案溫度鏈建議使用 0.001°C，MV 獨立使用百分比。FbPid 目前仍是 0.1°C，正式串接的換算邊界尚待完成。

## 絕對／相對的已知語意

依手冊範例，可以確認副控 SV 的允許範圍：

- 絕對模式：下界=L，上界=H。
- 相對模式：下界=主控 SV＋L，上界=主控 SV＋H。

例如主控 SV=220°C、相對 L=−20°C、H=40°C，副控 SV 的界限為 200～260°C。原表預設 H=600、L=−100，在 0.1°C 刻度下為 +60／−10°C。

這只確認界限語意，**不能據此推定主控 MV 如何換算副控 SV**，例如將 0～100% 線性映射至 L～H 的公式並未由這份欄位證實。Offset、濾波與最終限幅的處理順序也需另訂契約。

## 副控保護溫度：融入既有架構

此功能與副控 SV 上限不同：SV 限制是限制目標；保護溫度是檢查實際副控 PV，不能用 SV 限制取代。

建議責任分工：

1. L05 提供正確副控來源、加熱模式與有效量測。
2. 比較結果作為保護狀態／請求，使用既有 SYSTEM／Safety 的適當服務處理，不建立第二套輸出優先權。
3. 既有輸出流程依許可／抑制狀態控制副控候選 MV；手動、AT 或模式切換不能形成旁路。
4. 量測無效時沿用既有 Sensor 失效處置，不能把無效值當成低於門檻而解除保護。
5. 需另外定義解除遲滯、是否鎖存、恢復條件、熱／冷雙輸出適用範圍及主控積分追蹤／凍結，避免副控受限時主控持續積分。

原表以 0 表示功能停用，會與有效的 0°C 門檻混淆；本專案可採獨立 enable 與門檻，若未來相容原協定再於轉換層解碼。此為建議，尚未實作。

保護門檻列為介於「副控 SV 上／下限」，但相對模式的 SV 界限是偏差、保護溫度看起來是絕對溫度，兩者不能直接以原始數值比較；驗證政策需釐清後定案。

## 尚未明確的資料與契約

- 完整主控 MV→副控 SV 公式、MV 正負範圍與相對模式的基準。
- 濾波編號的演算法、取樣週期依賴、0 值、初始化及重設行為。
- Offset／濾波／限幅的先後，以及超範圍的數值處置。
- 一鍵校準的穩定條件、界限計算、失敗條件、寫入／保存規則。先前手冊描述讀為 9 後寫 1，這次表格寫任意值；不得直接採其中一種作為相容結論。
- 一鍵校準欄位雖列讀寫範圍 0～1，監看狀態卻有 9；應將命令與狀態語意分開，不以設定值檢查拒絕讀回 9。
- 主／副控 AT 期間另一個迴路如何運行、切換完成時怎麼移交狀態。
- 副控保護的解除／鎖存／感測失效政策，以及相對模式下門檻驗證。
